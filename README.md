# Prady Language Support for VS Code / Antigravity IDE

Full editor support for the **Prady Programming Language** (`.pr`).

## Features
- 🎨 **Syntax Highlighting**: Keywords, types, functions, comments, decorators (`@test`), architecture blocks (`architecture`, `layer`, `spec`).
- ⚡ **Code Runner Integration**: Press `Ctrl+Alt+N` or click the Run button to execute `.pr` files with `prady run`.
- 🔍 **Error Diagnostics**: Error and warning highlighting with precise spans and problem matchers.
- 📐 **Formatting & Brackets**: Auto-closing brackets, comments (`//`), and smart indentation.
- 💡 **Snippets**: Quick expansion for `fn`, `main`, `let`, `letmut`, `arch`, `struct`, and `@test`.
